      Host accounts
      
        
      
      
      
      
      
        
      
        
        
        Login output
        
        
        
      
        
      
        
        
        Add a host account
        
        
        
        
        
        
        
      
        
      
        
        A repository is bound to its host account by name in its
        .leiser/config.toml, for example
        host_account = "Work GitHub". The harness then sets the
        commit author and the account's credentials in the repository's local
        git config only, and checks the account before every push.
      
        
            
    
      
        
        
        Open a pull request
        
        
      
        
      
        
      
        
        
        
        
        
        
      
        
      
        
        The harness checks the repository's host account, pushes the chat's
        branch and opens the pull request with that account. A chat has at
        most one pull request; later pushes update it.
